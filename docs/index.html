This page runs the project's actual trained CNN, the same cnn_model.keras produced by src/train.py. Its weights were exported to a flat file (weights_b64.json + manifest.json) and are evaluated by a small hand-written JavaScript forward pass (convolution, max-pooling, dense layers, softmax; no TensorFlow.js), checked against the Keras model until the outputs matched. Before recognising a drawing, the page thins every stroke to a 1-pixel line and redraws it with one fixed pen, so pen size and digit size don't change the answer; the small picture under the result shows exactly what the model receives. "Try a real MNIST test digit" loads an actual image from the 10,000-image test set so you can compare the prediction to its true label yourself.
